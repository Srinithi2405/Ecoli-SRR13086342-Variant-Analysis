# Data

Raw sequencing data are not stored in this repository because the FASTQ
files are large.

## Source

NCBI Sequence Read Archive (SRA)

- Accession: SRR13086342
- Organism: Escherichia coli
- Platform: Illumina MiSeq
- Strategy: Whole Genome Sequencing
- Layout: Paired-end

The raw reads can be downloaded directly from NCBI SRA using the accession
above.
